# Environment assets

`sky-garden-clouds.png` was created for this project with the built-in image generation tool on 7 November 2026. It is 2172 x 724 pixels and used as the sky garden wall and ceiling mural.

Prompt: High resolution panoramic sky texture for an immersive dreamcore 3D game indoor sky garden mural. A tranquil luminous blue sky with detailed soft white cumulus clouds, delicate blush peach light, natural volumetric structure and fine wisps. Only sky and clouds edge to edge, no ground, horizon, sun disc, objects, text, frames or walls. Airy cloud clusters, generous blue sky, photographic detail, wide 3:1 composition.

`cloud-soft.svg` is an original procedural gradient used by the exterior cloud volumes. No third-party runtime texture or HDRI service is needed.
